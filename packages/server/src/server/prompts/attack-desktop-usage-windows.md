Prefer {{refs}} from desktop_snapshot, desktop_find or marked screenshots over coordinates; refs go stale after the window changes, so re-snapshot. Coordinates are pixels of your latest desktop_screenshot. If a snapshot reports tree quality none (games and custom-drawn UIs), take screenshots with grid: true and click coordinates; hold keys with desktop_key holdMs for movement and turn the camera with desktop_mouse move_rel. Input tools take screenshotAfter: true to return a screenshot with the result. Use desktop_wait (until stable) instead of guessing delays. If the window vanishes, call desktop_app status before concluding anything. When you find a defect, call submit_finding with desktopScreenshot: true so the owner sees the window.
