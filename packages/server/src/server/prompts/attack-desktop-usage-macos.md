Prefer {{refs}} from desktop_snapshot, desktop_find or marked screenshots over coordinates; refs go stale after the window changes, so re-snapshot. Coordinates are pixels of your latest desktop_screenshot. In key chords and click modifiers, cmd is the command key. A game or custom-drawn UI that reads the keyboard or mouse directly may ignore synthetic input. The app's menu bar is listed at the end of desktop_snapshot; press an item with desktop_click on its ref (never a coordinate) and expand one with snapshot root: its ref. Quit, Hide, Close All, the Apple menu and items whose shortcut is a refused chord are refused. Input tools take screenshotAfter: true to return a screenshot with the result. Use desktop_wait (until stable, text or gone) instead of guessing delays. If the window vanishes, call desktop_app status before concluding anything. When you find a defect, call submit_finding with desktopScreenshot: true so the owner sees the window.
