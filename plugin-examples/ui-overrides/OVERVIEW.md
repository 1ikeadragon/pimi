UI Overrides is a small example of changing Pimi's own interface from a plugin. It draws your chat messages as right-aligned bubbles, adds the git branch next to each workspace in the sidebar, and replaces the About page in Settings.

Settings, Plugins, UI Overrides has a switch that makes the message bubble fail on purpose. Pimi then shows its own message and lists the error on the Plugins page. Plugins that change the interface apply to the whole app, including workspaces on other hosts. Turn on safe mode on the Plugins page to see Pimi without plugin changes.
