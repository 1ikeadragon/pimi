# Contributing to Pimi

Open a [Pimi issue](https://github.com/1ikeadragon/pimi-releases/issues/new/choose) with the app version, platform, and steps to reproduce. Include a short recording for UI bugs and redact private information from logs.

Keep pull requests focused. Describe the user-facing change, how you verified it, and any platforms you could not exercise. See the [development guide](pimi/README.md) for setup and the [QA guide](docs/qa.md) for the available checks.

Pimi uses the upstream plugin and SDK contracts. See the [plugin guide](docs/plugins.md) and [SDK reference](public-docs/sdk/reference.md).
