# Contributing to Pimi

Open a [Pimi issue](https://github.com/1ikeadragon/pimi/issues/new/choose) with the app version, platform, and steps to reproduce. Include a short recording for UI bugs and redact private information from logs.

Pimi is a passion project and does not accept pull requests or other code contributions. Bug reports through issues are welcome. See the [development guide](pimi/README.md) to build it yourself.

Pimi uses the upstream plugin and SDK contracts. See the [plugin guide](docs/plugins.md) and [SDK reference](public-docs/sdk/reference.md).
